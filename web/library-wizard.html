Library Wizard

The phonoteca shelf a pro DJ would spend years building by hand — named drawers inside drawers, deployed on your drive in seconds.

Radio-digital shelving for the modern DJ: clarity in the set, event templates in seconds, and a folder architecture any professional would pay to own — built into MDJPRO, only from Miami DJ Beat.

Library Wizard creates the folder architecture (the DNA). It does not move or tag files — you curate inside those drawers. That is by design: structure first, then mastery.

MDJPRO workflow

Hub → Load Root → Library Wizard → Start Scan → Tag Master

What Library Wizard does not do

  • It does not import or move audio/video files automatically.
  • It does not write ID3 tags — that is Tag Master.
  • BUILD deploys only the active DNA tab — not every tab at once.
  • It is not free — MDJPRO Premium (libraryWizard) required.
