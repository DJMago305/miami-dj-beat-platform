Tag Master · Metadata Engine

Library Cleaning

The metadata brain behind Library Cleaning — batch ID3 editing, atomic validation, and professional tag hygiene on tracks you already indexed in MDJPRO.

Where Library Wizard builds the shelves, Tag Master labels every record: title, artist, album, comments, cover art — cleaned, verified, and written back to disk locally. No cloud upload. You confirm every Save.

Tag Master edits metadata inside your files. It does not deploy folder DNA — that is Library Wizard. Typical flow: Load Root → Start Scan → clean tags here → Save writes physical ID3.

Six workflow pillars

1
Batch ID3 EditorSeven core fields with real-time validation — Title, Artist, Album, Comments, and more. Tri-state draft for multi-select.
2
Visual MonitorCover art, path, bitrate, duration, and key — adjustable columns. Audio preview and MP4 scrub before you commit.
3
Cleaning ArsenalMagic Eraser, Auto-Tag heuristics, and emoji cleanup — strip junk characters and normalize strings in batch.
4
Filename ↔ TagMap filename patterns into ID3 when tags are empty or inconsistent — DJCity, pools, feat. parsing included.
5
Import SandboxBulk-load audio and video from Finder into the editor — independent of the last scan when you need a focused session.
6
Save & DistributionPhysical ID3 write with round-trip validation. MDJ Distribution previews moves into your Wizard DNA — you confirm before anything moves.

Where Tag Master sits in MDJPRO

Hub → Load Root → Start Scan → Tag Master → Results

What Tag Master does not do

  • It does not deploy folder DNA — Library Wizard owns structure.
  • It does not silently rewrite your library — you confirm before Save.
  • It does not auto-commit when you change rows — draft changes need an explicit Save.
  • It requires MDJPRO Premium (tagMaster) — processing stays 100% local on your Mac.

Today vs what comes next

  • Today: batch ID3, cleaning tools, cover/video preview, verified local write.
  • You: unidirectional workflow — avoid editing the same files outside MDJPRO mid-session.
  • Next: deeper AI-assisted tagging — in development; today Auto-Tag uses expert heuristics, not autopilot.
