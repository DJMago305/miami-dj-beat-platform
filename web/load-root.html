Load Root · Master Folder

Load Root

The first step on the MDJPRO Hub — point at your master music folder on Mac. One macOS grant, one persistent security bookmark, local access for Scan, Wizard, and Tag Master.

Load Root does not scan or move files: it authorizes the macOS sandbox on the folder you pick and registers it as a ScanStore source. All processing stays on your drive — no cloud upload.

Typical flow: Splash → Hub → Load Root → (Library Wizard / Tag Master) → Start Scan → Results. Requires Basic or Premium license (not Trial). If the bookmark goes stale, run Load Root again.

Where Load Root sits in MDJPRO

Hub → Load Root → Wizard / Tag Master → Start Scan → Results

What Load Root does not do

  • It does not scan audio or video — that is Start Scan.
  • It does not deploy folder DNA — that is Library Wizard (Premium).
  • It does not edit ID3 — that is Tag Master (Premium).
  • It does not replace protected USB volume permission — use Grant Disk Access on Results when needed.

Today vs what comes next

  • Today: localized PERMISOS-007 panel, statusLine feedback, green badge with source count.
  • You: pick the real root of your library — Serato, Rekordbox, or VirtualDJ read from there.
  • Next: inline Hub hints (copy only, PERMISOS-007 Phase 2+) — Splash → Hub flow unchanged.
