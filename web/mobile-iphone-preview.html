Vista previa estilo iPhone

Herramienta solo para desarrollo local. Carga cualquier página del sitio dentro de un marco (~390×844px). Añade en la URL el id del DJ y view=public para simular el escaneo del QR.

El servidor debe escuchar en 0.0.0.0 si quieres abrir esta misma URL desde un iPhone real. Ejemplo: python3 -m http.server 8000 --bind 0.0.0.0
