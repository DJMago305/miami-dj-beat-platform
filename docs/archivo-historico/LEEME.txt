Miami DJ Beat — material FUERA del proyecto activo
==================================================
Fecha del archivo: abril 2026

Qué es esta carpeta
--------------------
Aquí está lo que se separó del repositorio de trabajo para que el proyecto
“de verdad” quede casi solo con:

  • web/          → sitio público (lo que publica Vercel desde la carpeta web)
  • supabase/     → código del backend (funciones, migraciones)
  • .gitignore, .gitattributes, .cursorrules, README.md en la raíz del repo

Todo lo que movimos aquí son cosas que NO hacen falta para que la web
funcione día a día: documentación, informes, SQL de referencia, scripts
viejos, respaldos de rentals, flujos de agente (.agent), estrategia (strategy), etc.

Cómo usar esto
--------------
• Si algún día necesitas un archivo de aquí, cópialo de vuelta al repo donde
  corresponda (o pregunta antes de mezclar de nuevo).
• No borres esta carpeta sin revisar: puede tener políticas o SQL que quieras
  conservar como referencia.

El código vivo sigue en: miami-dj-beat-platform (tu copia local) y en GitHub.


Nota: esta carpeta solo existe en TU Mac (Escritorio). Si clonas el repo en otra máquina,
no traerá este archivo: vive fuera del repositorio Git.
